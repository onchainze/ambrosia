# Ementa da Família

App web (um único ficheiro `index.html`) para planear as refeições da semana em família, em português.

## Funcionalidades
- Receitas por tipo (Carne, Peixe, Sopa, Massa e arroz, Vegetariano, Pequeno-almoço, Sobremesa)
- Filtros por autor, tempo, calorias, proteína, açúcar e vegetariano
- Informação nutricional aproximada por pessoa
- Plano semanal (pequeno-almoço, almoço e jantar)
- Lista de compras automática, por secção do supermercado
- Exportar receitas e lista de compras em texto, e o calendário e a lista em PDF ou imagem
- Funciona no telemóvel e pode ser adicionada ao ecrã principal

Os dados (plano, favoritos, lista) ficam guardados no navegador de cada aparelho.

## Como usar
Abra o `index.html` no navegador, ou publique com GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / `/ (root)`).

## Receitas e fontes
As receitas são versões em português escritas para esta app, com valores nutricionais aproximados.
As que têm a etiqueta de autor (Jamie Oliver, Pingo Doce) são inspiradas nos pratos dessas fontes,
com ligação para a receita original. O texto das receitas originais não está incluído.
